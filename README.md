# GoldenJunk 🗑️

## About the Project
GoldenJunk is a fast-paced, arcade-style sorting game developed in Unity. The core objective is simple: catch falling trash bags and sort them into the correct trash cans based on their colors. As time passes, the game is designed to become increasingly chaotic and challenging.

This project was created to practice core game loop mechanics, object interactions, and difficulty scaling in Unity.

## Gameplay Mechanics
* **Sorting:** Trash bags fall from a platform, and the player must direct them into the matching colored bins.
* **Increasing Difficulty:** The falling speed of the trash bags increases as the game progresses to challenge the player.
* **Dynamic Environment:** The trash cans periodically change their positions to test the player's reflexes.

## Development Status & Known Issues (WIP) 🚧
This game is currently a **Work in Progress (WIP)**. While the core sorting mechanics and physical interactions are functional, there are a few known bugs I am actively analyzing:
* **Bin Swapping Bug:** The mechanic where trash cans swap positions is currently unstable and sometimes fails to trigger or update correctly.
* **Pacing/Speed Issue:** The speed multiplier (difficulty curve) is progressing too slowly, making the gameplay pacing feel unbalanced at the moment.

## Tools & Technologies
* **Game Engine:** Unity (C#)
* **Code Editor:** Visual Studio Code
* **Development Note:** I utilized AI assistants during the development process to help structure the C# scripts, debug logic, and build the core mechanics.

## How to Run the Project
1. Clone this repository to your local machine.
2. Open Unity Hub and select `Add project from disk`.
3. Select the `GoldenJunk` root folder.
4. Open the main scene located in the `Assets` folder and press Play!
